# MNIST Subset Access

The project uses digit-1 and digit-7 subsets derived from MNIST. The provided NPZ file is excluded until its precise provenance, preparation history and redistribution terms are documented.

Users must obtain an authorised equivalent and set `MNIST_SUBSET_PATH` to the NPZ file. The expected arrays are the training images and labels plus test images and labels used by the notebook.

The inspected subset contains 50 training examples per class and a test collection of 100 digit-1 and 900 digit-7 images. The underlying dataset terms remain separate from this repository's MIT licence.
