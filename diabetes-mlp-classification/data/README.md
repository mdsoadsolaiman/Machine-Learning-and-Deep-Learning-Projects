# Diabetes Dataset Access

This project uses a de-identified tabular diabetes-classification dataset. The supplied description associates it with NIDDK-style variables, but the exact source and redistribution licence have not been verified; therefore the training and test CSV files are excluded.

Users must obtain the data lawfully and set `DIABETES_DATA_DIR` to:

```text
train_data.csv
test_data.csv
```

The raw files contained 614 training and 154 test records. Cleaning retained 579 training and 153 test records. This academic exercise is not a clinical diagnostic system.
